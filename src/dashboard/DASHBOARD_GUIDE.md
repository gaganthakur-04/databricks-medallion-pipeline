# Dashboard Guide

## Required Visualizations

| Tile | Type | Source |
|------|------|--------|
| Top 10 products by revenue | Bar | `gold.sales_by_product` |
| Customer revenue distribution | Histogram | `gold.revenue_by_customer` |
| Customer segmentation | Pie | `gold.customer_segmentation` |

## Setup

1. Create a Databricks SQL Dashboard
2. Import queries from `dashboard_queries.sql`
3. Configure visualization types and add filters
4. Capture screenshot or link in `candidate-info.md`
